# ============================================================
# CPU-only 环境的版本约束（由 requirements-cpu.txt 通过 -c 引入）
#
# 不要单独安装这个文件：它只用来"约束" requirements.txt 里的候选版本。
#
# 为什么不用在 requirements-cpu.txt 里直接再写一条 `torch==…+cpu`：
# requirements.txt 里是裸 `torch`（= 任意版本），pip 解析时会把
# "裸 torch" 与 "torch==2.12.1+cpu" 当成两个依赖，先下载当时最新的
# torch（实测 2.14.1+cpu，约 190 MB），发现与 pin 冲突后再回退重下
# 2.12.1+cpu（约 190 MB）——白下载一次。写成约束后 pip 从第一步就
# 只在 2.12.1+cpu 里选，只下一次。
# ============================================================
torch==2.12.1+cpu
