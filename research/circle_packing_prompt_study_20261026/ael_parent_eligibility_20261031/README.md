# AEL parent eligibility - completed 2026-10-31

Thirty historical programs from the existing static shortlist were checked once using the registered N=26 evaluator and 20-second cap. **22 returned valid positive scores; 8 timed out.** The best measured score was **2.5338065697852596**, from historical sample **9180**. Eligible options occupy **two** branches of the identified frozen HNSW graph. No program reached 2.6360 in this diagnostic.

This is parent-eligibility evidence, not a set of LLM-generated offspring or a completed AEL evolution. The 22 eligible options were not automatically declared a chosen population or mating schedule.

Eligibility here is conditional on the existing 30-program static shortlist; the diagnostic is not an exhaustive runtime search of the 14,000-record archive or proof of an optimal parent pool.

The existing code files are linked by source path and hash in the manifest; their contents and archived scores were not modified or copied into another code-data collection. The 14,000-record dataset was not duplicated. Browser profiles and transfer ZIPs are local transport/verification artifacts and are excluded from the research backup.

Reusing the registration does not authorize another execution: completed results and exclusive-start records prevent a silent rerun. A changed evaluator, environment, budget, parent-selection rule or model test requires a separately identified condition with complete history.
